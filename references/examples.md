```
• 对话轮数：280 轮
• 会话时长：3 天
• 预估成本：$0.19/天

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 保留最近 20 轮完整对话
• 将早期 260 轮压缩为 8 段摘要
• 保留所有代码块和配置
• 保留 12 个待办事项

1. 保存完整备份到 ~/.openclaw/backups/
```

## 🎓 场景 8: 学习使用压缩功能

### 对话示例

```
用户：第一次用这个功能，怎么用？

AI: 欢迎使用 Context Compressor！让我教你如何使用。

📚 Context Compressor 使用指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 什么是上下文压缩？
简单说，就是压缩对话历史，减少 token 消耗，
同时保留重要信息。

💰 为什么要压缩？
• 省钱：减少 60-80% 的 token 消耗
• 更快：短上下文 = 快响应
• 避免超限：防止超出模型限制

📱 怎么用？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   说："压缩对话" 或 "节省 token"

2️⃣ 自动压缩（推荐）
   说："启用自动压缩"
   系统会在需要时自动压缩

3️⃣ 查看状态
   说："查看压缩状态"

4️⃣ 恢复历史
   说："恢复之前的对话"
```
