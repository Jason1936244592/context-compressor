## ⚙️ 配置选项

### 自定义压缩阈值

编辑 `SKILL.md`，修改：

```yaml
metadata:
  threshold_tokens: 50000  # 改为你的阈值
```

### 自定义保留轮数

编辑 `scripts/compress.py`，修改：

```python
self.recent_turns = 20  # 改为你想保留的轮数
```

### 自定义压缩比例

编辑 `scripts/compress.py`，修改：

```python
self.target_ratio = 0.7  # 0.5=更激进，0.8=更保守
```

## ⚠️ 常见问题

### Q: 压缩会丢失信息吗？

A: 不会。压缩前会：
1. 自动备份完整对话
2. 保留所有代码和配置
3. 保留待办事项和关键决策
4. 你可以随时恢复

### Q: 多久压缩一次合适？

A: 建议：
- 轻度使用：每天 1 次或手动
- 中度使用：每 12 小时或达到 50K tokens
- 重度使用：自动触发（推荐）

### Q: 压缩后响应会变快吗？

A: 会。通常提升 30-50% 的响应速度。

### Q: 能恢复压缩前的对话吗？

A: 可以。说"恢复对话"即可查看和恢复备份。
